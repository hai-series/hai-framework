## 已有证据与待验收范围

- T001 两个启动回归测试先暴露缺失配置。修复后通过 Codex 原生容器和真实网关，DeepSeek `session/new` 复测中位数为 9.97 ms。DSH 和 Goose 的真实原生程序通过本地网关握手、prompt 和恢复。
- T002 SQLite、PostgreSQL、MySQL、Podman 与 Docker 验证执行领取、资源限额、进程退出和文件产物边界。未知状态保留资源占用，由运维核对。
- T003 多路连接测试先因缺失会话通道失败。Podman 测试验证三种分配模式、切换、审批和跨用户隔离。独立进程配合 PostgreSQL 验证多个 API 入口、事件重连、取消和失去原生连接后的关闭。
- T004 外部 MCP 使用真实 HTTP SDK，受管 Office 测试验证从 broker 到产物发布，并检查使用的是同一个预热容器 ID。静态清单可设预热和实例数上限。独立浏览器镜像已验证经代理访问授权的本地 HTTPS、拒绝未授权域名和跳转。浏览器接入受管作业及生产出口仍待验收。
- 受管任务可载入已授权的只读工作区快照并在私有目录处理副本。模式切换可带入用户确认的摘要。持久可写 Git 工作区和跨 Worker 原生历史恢复仍使用独立的可信工程流程。技能正文与记忆写入可由应用注入，原生技能目录挂载及内置 Agent 的共享执行仍有单独验收门槛。
- 本机 CLI 下载门禁切换官方源复测通过。全脚手架浏览器组要求 Google Chrome，当前主机缺少该程序。文档站以同轮构建的静态产物在 Chromium 下截取桌面、手机和配置页。
