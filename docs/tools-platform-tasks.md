# 工具平台与 Agent 产物工作台实施清单

## 需求和确认依据

- 需求文档：[能力清单与建设建议](codex-capabilities-and-tools-plan.md)，重点为第 4～7 节。
- 用户确认：本轮明确“基本认同你的方案”，要求实施，补充可扩展、可选择启用、分布式多节点、控制实现及部署复杂度、通过 `<模块名>.xx` 暴露，并更新 `apps/agent`、录制演示验收及同步 README、skill、page。
- 后续明确决定：不考虑旧版本兼容性，按最佳边界实施；定义/注册只用 `tools.xx`，AI 通过 `ai.tools.adapt` 做协议转换，不保留旧 `ai.tools.define/createRegistry` 或旧目录桥接。
- 易用性要求：常用操作有表单、示例、进度和恢复；通用组件归 UI、可复用执行归 Tools，Agent 保留配置、权限和资源归属的薄装配。
- 最终交付要求：完成后全面审查安全、性能、易用性、扩展性、规范与需求覆盖；录屏包含全部核心操作。按任务分别提交，全部审查和验收通过后统一合并并推送 `main`，中途不合并未完成的功能。
- 文档是本轮建设基线；“后续按需求”的多人实时协作、桌面控制、宠物等不作为本轮必需交付。现有工具目录及连接器仍须能接入扩展。
- 必需交付保留前三阶段完整范围：Tools 中立内核、既有文件作业迁移、可编辑产物、图片/音频、网页预览/采集/搜索、图表、网址转视频、必要的原生文档生成，以及工具启用管理、扩展方法、多节点验收和使用演示。
- 主分支：`main`；规划起点：`3261b46e`。已验收文档基线与实现基线：未建立。
- 当前授权覆盖上一方案中的边界和功能；不新增通用队列、持久审批模块、另一套产物框架或第二份执行租约。

## T001 执行记录

- 范围：纯工厂式 `tools.define/createRegistry`，中立输入输出、授权和取消；AI 保留模型协议转换；文件作业迁入 Tools。轻量入口保持浏览器可用，作业仅服务端。
- 复用：当前 Zod 执行逻辑、Core HaiResult/i18n、MCP 服务和 Runner；不新建数据库或作业调度器。
- 变更影响：新包、AI 工具类型与执行适配、实际消费者、构建依赖及独立镜像路径；同步 API/README/skills。
- 目标测试：模块入口的直接调用与 AI 调用一致性、授权拒绝、非法输入、取消、批量执行和浏览器依赖隔离；既有工具操作协议回归。
- Red：CLI 添加工具在依赖缺失处失败；AI 协议适配 8 项因缺少 adapt 失败；中立内核新增名称/异步 Schema/自定义执行绕过/同步截止边界均先失败后修正。
- Green：中立内核 12 项、AI 相关 243 项、CLI 相关 56 项、CI 路径 20 项通过；独立工具先 6 项，扩展媒体协议后 16 项通过（媒体子进程替换，真实渲染仍属 T003/T004）。
- 定向门禁：`tmp/validation/tools-platform-t001/summary.json` 记录 18 项全部通过，包含 Tools/AI/CLI/Playground 类型与 lint、相关构建和测试。公开 API 串行复测 24/24 Node 包导入、37 浏览器入口通过；API 清单、环境清单、skill/README 及本地链接检查已通过。
- 脚手架门禁：首次真实运行失败于本机缺少 Chrome channel 路径及国内镜像下载。已确认可通过测试命名空间挂载现有 Chrome，并使用门禁支持的官方源；待最终稳定后定向复验，不记为通过。曾与构建并发的 API 检查无效，已由上述串行复测替代。
- 任务提交：首个工具内核与独立作业提交准备中；后续服务与应用集成仍继续，不因局部门禁通过标记整体完成。
