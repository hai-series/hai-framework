## PostgreSQL 验证

先运行 Runner 的真实容器回归。变更前节点不会等待同一个结构锁，同名表还会让索引创建静默跳过。改用 RelDB 的事务结构准备后，三个独立进程在同一 PostgreSQL 上等待并完成空库和旧库初始化。故意制造索引名冲突会回滚当次创建的 Runner 表，移除冲突后同一实例可以重试。旧库测试保留升级前提交的任务。
