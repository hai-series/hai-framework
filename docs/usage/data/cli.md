## 数据库与缓存

生成、构建、部署辅助和离线诊断命令不创建框架级数据库表或 Redis 键。生成的应用在实际运行时由所启用模块创建各自的表与键。

## 文件产物

| 文件                       | 数据与用途                                             |
| -------------------------- | ------------------------------------------------------ |
| 目标目录的源码及清单       | 新应用、工作区与所选功能对应的配置和资源               |
| 成功产物的 `manifest.json` | 产物及构建来源，随构建目录保留                         |
| 离线诊断包                 | 路径由调用方选择。包内结构参见 [feedback](feedback.md) |
| 发布文件                   | 归档和服务端发布状态参见 [deploy](deploy.md)           |
