# @h-ai/api-contract データ構造

[原文（中国語）](api-contract.md) · [設定](../configuration/api-contract.ja.md) · [API リファレンス](../function/api-contract.ja.md)

契約はエンドポイントのメタデータをコードに保持します。データベースの列、キャッシュ、セッションは業務モジュールが管理します。リクエストの既定値は省略したリクエスト項目に適用されます。

| テーブル・キー・成果物 | 形式と管理元 |
| --- | --- |
| Endpoint / エンドポイント | HTTP メソッド、パステンプレート、パス・クエリ引数、リクエストとレスポンスのスキーマ。 |
| `HaiResult<T>` | 成功データまたは失敗エラーを判別できる形式。 |
