# storage 数据结构

[数据结构索引](README.md) · [模块配置](../configuration/storage.md) · [功能说明](../function/storage.md)

## 数据库与缓存

模块没有 SQL 表或 Redis 键。对象后端持有正文和元数据，业务表按需引用对象 key。

## 对象与元数据

| 字段           | 用途                                                         |
| -------------- | ------------------------------------------------------------ |
| `key`          | 调用方定义的对象标识，支持路径层级，UTF-8 长度上限 1024 字节 |
| `size`         | 字节数                                                       |
| `contentType`  | MIME 类型，上传时可指定                                      |
| `lastModified` | 后端报告的修改时间                                           |
| `etag`         | 后端提供时用于标识版本与条件操作，语义依后端而定             |
| `metadata`     | 自定义字符串键值映射，上传时可提供                           |

S3 将字节和附加属性保存在 bucket 内，保留和版本策略由部署管理。local 将字节保存到根目录中的相应路径，同级 `.hai-storage-meta/<文件代际>.meta.json` 按实际文件代际保存 `contentType` 与 `metadata`。内部元数据和临时上传文件不能作为普通对象访问。预签名 URL 由后端按请求到期时间生成。
