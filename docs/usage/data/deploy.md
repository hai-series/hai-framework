## 数据库与缓存

模块不创建 SQL 表或 Redis 键。工作目录、目标主机和托管供应商各自持有发布或资源状态。

## 文件状态

| 路径                         | 数据与用途                                                              |
| ---------------------------- | ----------------------------------------------------------------------- |
| 构建目录的 `manifest.json`   | 产物类型、应用与构建标识、镜像或文件清单及校验信息                      |
| 归档根目录的 `manifest.json` | 发布声明及元数据，与 `apply.sh`、`config/`、`images/`、`.hai/` 一同分发 |
| `.hai/SHA256SUMS`            | 内容的校验摘要，应用前验证                                              |
| `<root>/releases/<id>/`      | 按部署 ID 保存的发布目录，含 Compose 与运行配置                         |
| `<root>/.deploy.lock`        | 发布目录对应的文件互斥锁。持有进程存续期间保有锁，删除文件会破坏协调    |
| `<root>/steps-<id>.jsonl`    | 逐条保存 `stage` 步骤、`status` 结果和 `durationSeconds` 耗时           |
| `<root>/result-<id>.json`    | 指定发布的最终结果，可在连接中断后读取                                  |
| 目标主机的运行配置           | 可能含连接与应用凭据，随发布和目标主机管理                              |

文件锁协调访问同一发布根目录的操作，业务数据仍由相应模块与供应商管理。
