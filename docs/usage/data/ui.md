## 这些数据用来做什么

### 记住用户选的主题

对应结构：`theme`。

浏览器保存主题偏好，下次打开页面时仍使用用户的选择。

```json
"dark"
```

dark 表示选择深色主题。它保存在 localStorage，没有自动过期时间；页面仍需包含相应 CSS。

### 记住用户选的语言

对应结构：`hai-locale`。

浏览器保存语言偏好，重开页面时据此选择已安装的翻译。

```json
"zh-CN"
```

zh-CN 表示简体中文，不能据此推断应用已经安装任意语言包。

### 记住是否完成新手引导

对应结构：`hai-guide:orders:intro`。

用来避免每次打开同一应用都重复弹出已经完成的引导。

```json
{
  "version": 1,
  "status": "completed",
  "updatedAt": 1794873600000
}
```

orders 范围的 intro 引导第1版已经完成。默认写入 Cookie；升级引导版本后可以再次提示，updatedAt 以 Unix 毫秒记录完成状态的更新时间。

### 切换页面后接着开始引导

对应结构：`hai-guide-pending`。

引导需要先跳转页面时，在 sessionStorage 暂存目标，下一页核对后继续。

```json
{
  "id": "intro",
  "scope": "orders",
  "route": "/orders",
  "createdAt": 1794873600000
}
```

表示到 /orders 后开始 orders 范围的 intro；5分钟内、范围和页面都吻合才恢复，它不是已完成引导的记录。

## 字段、存储与清理参考

### 数据库与缓存

组件不创建数据库表或 Redis 键。表单提交、上传文件和审批结果由应用自己的服务端接口保存。从哪读取分页数据，也由应用决定。

`ArtifactWorkspace` 的当前草稿、版本列表和冲突提示只保留在当前组件实例中，不写入浏览器持久存储；产物内容、版本历史、资源归属与冲突检查由宿主服务负责。`ToolWorkspace` 的工具目录和执行回执同样来自宿主，组件只持有当前表单、查询计时器和取消信号；任务的持久状态、租约与事件由实际执行服务维护。

### 浏览器存储

| 键                          | 位置和值                                                                                          | 默认值与生命周期                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `theme`                     | localStorage 中的主题 ID。自定义启动脚本用指定键保存 `themeId`、可选 `themeColor` 和语言项的 JSON | 读不到有效设置时使用应用设置的默认主题；应用未指定则用 `light`。保存的主题没有过期时间     |
| `hai-locale`                | localStorage 中的语言代码                                                                         | 可用 `persistKey` 改名。没有已保存的语言时，按应用的语言设置和浏览器偏好选择               |
| `<persistKey>:<scope>:<id>` | 为每个应用指定的范围和每条新手引导分别记住进度                                                    | `persistKey` 默认 `hai-guide`。支持 Cookie（默认）、localStorage、内存；版本升级可重新提示 |
| `<persistKey>-pending`      | 页面跳转时写入 sessionStorage，供下一个页面恢复还未开始的引导                                     | 按会话保存，恢复时检查有效性                                                               |
| 组件配置的键                | 例如可调整表格的列宽偏好                                                                          | 应用决定页面或用户的命名隔离                                                               |

服务端渲染时，每个请求保留各自的状态。浏览器拒绝读写本地存储时，组件使用其默认值，或在当前页面的内存中临时保存状态。
