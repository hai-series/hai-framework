## 数据库与缓存

组件不创建数据库表或 Redis 键。业务表单、文件、审批和分页由宿主服务保存。

## 浏览器存储

| 键                          | 位置和值                                                                                          | 默认值与生命周期                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `theme`                     | localStorage 中的主题 ID。自定义启动脚本用指定键保存 `themeId`、可选 `themeColor` 和语言项的 JSON | 缺失、非法或存储不可用时用宿主默认主题，模块默认 `light`，无 TTL                           |
| `hai-locale`                | localStorage 中的语言代码                                                                         | 可用 `persistKey` 改名。缺失时按语言初始化选项和浏览器偏好选择                             |
| `<persistKey>:<scope>:<id>` | 按范围和引导 ID 保存进度                                                                          | `persistKey` 默认 `hai-guide`。支持 Cookie（默认）、localStorage、内存；版本升级可重新提示 |
| `<persistKey>-pending`      | sessionStorage 中跨页面导航的待启动引导记录                                                       | 按会话保存，恢复时检查有效性                                                               |
| 组件配置的键                | 例如可调整表格的列宽偏好                                                                          | 应用决定页面或用户的命名隔离                                                               |

SSR 状态随请求持有。浏览器存储不可用时按对应功能的默认或内存策略恢复。
