# Core のデータ

[简体中文](core.md) · [English](core.en.md) · [Core の設定](../configuration/core.ja.md) · [設定 API](../function/core.ja.md#config-api)

Core は以下のデータを実行中のプロセスのメモリに保持します。データベースのテーブルや Redis のキー、ディスクキャッシュは作成しません。Node プロセスごとに必要な設定を読み込みます。

| データ               | 内容                                                                                                              |
| -------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 読み込み済み設定     | `core` などの名前で保存され、`core.config.get('core')` で取得します。検証時に補われる既定値はスキーマで決まります |
| ログ                 | レベル、時刻、関連情報。出力と保持期間はログのバックエンドが決めます                                              |
| モジュールの実行状態 | アプリが起動したモジュール、依存関係、現在の状態。新しいプロセスでは改めて起動します                              |
| リクエストと処理結果 | 同じリクエスト内で共有する追跡情報と、処理が返す成功値またはエラー                                                |
