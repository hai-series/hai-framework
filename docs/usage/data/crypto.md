# crypto 数据结构

[数据结构索引](README.md) · [模块配置](../configuration/crypto.md) · [功能说明](../function/crypto.md)

## 数据库

只有 RelDB 传输密钥仓库建表。哈希、签名、加密和独立解密未持久化消息正文或私钥。

| 表                                 | 字段与约束                                                                                                                                                |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hai_crypto_transport_client_keys` | `client_id` 为注册客户端主键，`public_key` 为 SM2 公钥，`created_at_ms` 为登记时间。可空 `expires_at_ms` 为到期时间，省略公钥 TTL 时为 NULL               |
| `hai_crypto_transport_requests`    | `request_key` 为客户端及请求标识组成的 JSON 数组字符串，也是唯一领取键，`expires_at` 为防重放记录到期的毫秒时间。重复领取拒绝，同一认证窗口内不得提前移除 |
| `hai_crypto_transport_capacity`    | `id` 为单行主键 1，`max_clients` 为共享登记容量，仓库默认 10000，`revision` 为容量更新代际，从 0 开始。不同节点使用同一个容量设置                         |

注册和回收使用共享数据库时间。客户端公钥与防重放记录各有到期策略，到期记录随仓库操作分批清理。

## 缓存键

| 逻辑键                                                | 值                     | 默认值与到期                                           |
| ----------------------------------------------------- | ---------------------- | ------------------------------------------------------ |
| `hai:crypto:transport:client:<clientId>`              | SM2 客户端公钥         | `ttlSeconds` 指定公钥寿命，省略时不过期                |
| `hai:crypto:transport:request:<clientId>:<requestId>` | `true`，表示请求已领取 | 原子写入，TTL 为当前时间距该请求认证窗口截止点的毫秒数 |

Redis/Cluster 仓库借用 [cache](cache.md) 连接和键前缀。生产不得提前驱逐仍有效的请求登记。显式 memory 仓库把类似状态保存在进程内，进程间不共享。
