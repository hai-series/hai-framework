# @h-ai/tools 数据结构

轻量工具定义和注册器没有自有数据库表、缓存键或持久租约。名称、Schema、处理函数和授权回调保存在当前进程中，`clear()` 或进程退出后不保留。

| 数据 | 所有者与生命周期 |
| --- | --- |
| 工具实现集合 | 宿主按配置注册，每个节点各自装配；不是任务共享状态 |
| 业务记录与文档版本 | 实际业务服务负责归属、版本冲突和保留期 |
| 执行任务、租约、状态和事件 | [Runner](runner.md) 保存与清理 |
| 输入文件和输出产物字节 | [Storage](storage.md) 保存，宿主验证授权文件/产物 ID |
| MCP 服务清单与 Broker | 当前由 [AI](ai.md) 管理 |

调用结果中的大文件应使用授权引用。不要将图片、视频或秘密写入工具定义、LLM 消息或任务事件。日志只保留经过脱敏的操作诊断。
