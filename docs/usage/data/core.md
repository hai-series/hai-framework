## 数据库与缓存

模块不创建数据库表、Redis 键或磁盘缓存。配置源可读取宿主的文件和环境变量，解析结果及模块运行时由当前进程持有。

## 进程内数据

| 数据           | 用途                                                               |
| -------------- | ------------------------------------------------------------------ |
| 配置加载结果   | 以模块名为键保存合并和校验后的配置。字段默认值由各模块 schema 应用 |
| 日志记录       | 事件级别、时间及上下文。日志后端决定输出和保留期                   |
| 模块运行时     | 维护声明、依赖与生命周期状态，进程重启后重新初始化                 |
| 上下文与结果值 | 类型化数据、追踪和错误信息，在调用或运行实例范围内传递             |
