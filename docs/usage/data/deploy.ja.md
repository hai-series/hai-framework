# @h-ai/deploy データ構造

<!-- translation: partial -->

[原文（中国語）](deploy.md) · [設定](../configuration/deploy.ja.md) · [API リファレンス](../function/deploy.ja.md)

デプロイ状態はファイルとリモートのリリース記録に保存します。アプリのデータベース、キャッシュ、オブジェクトストレージは独自のデータを保持します。

| テーブル・キー・成果物 | 形式と管理元 |
| --- | --- |
| Build manifest / ビルドマニフェスト | リリース情報、サービス成果物、ダイジェスト。部分デプロイの前に確認。 |
| Remote deployment / リモート配置 | 対象ごとのリリース内容と現在・復旧状態。ロールバックに必要なファイルと確認済みの基準を保持。 |
| Credentials / 認証情報 | 非公開ファイルに保存し、環境別に取得するプロバイダーの認証情報。 |

追加の設定項目や利用例は[中国語リファレンス](deploy.md)に掲載しています。
