# @h-ai/tools データ構造

軽量なツール定義とレジストリは、独自のデータベーステーブル、キャッシュキー、永続リースを持ちません。名前、Schema、処理関数、認可コールバックは現在のプロセス内に保持され、`clear()` またはプロセス終了後には残りません。

| データ | 管理主体とライフサイクル |
| --- | --- |
| ツール実装の集合 | ホストが設定に従って登録し、各ノードがそれぞれ構成。共有タスク状態ではない |
| 業務レコードと文書バージョン | 実際の業務サービスが帰属、バージョン競合、保持期間を管理 |
| 実行タスク、リース、状態、イベント | [Runner](runner.md) が保存とクリーンアップを担当 |
| 入力ファイルと出力成果物のバイト列 | [Storage](storage.md) が保存し、ホストが認可済みファイル／成果物 ID を検証 |
| MCP サービス一覧と Broker | 現在は [AI](ai.md) が管理 |

呼び出し結果の大きなファイルには、認可された参照を使ってください。画像、動画、機密情報をツール定義、LLM メッセージ、タスクイベントに格納しないでください。ログには機密情報を除去した操作診断のみを残します。
