## 設定の読み込み

このモジュールに独立した設定ファイルはありません。アプリは組み合わせる API 契約をコードで選びます。サーバーは IAM の設定を読み込み、CAPTCHA の有効化や使用できるログイン方式をログイン画面に返します。これらを変更する場合はサーバーが読み込む [IAM 設定](iam.ja.md)を編集してください。

引数・既定値・使用例は次を参照 [公開設定レスポンス](../data/api-contract.ja.md#public-settings)。
