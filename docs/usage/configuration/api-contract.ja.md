## 設定の読み込み

API Contract はコードで契約を定義し、独立した設定ファイルはありません。公開認証設定は応答データで、元のファイル設定は IAM などが管理します。

引数・既定値・使用例は次を参照 [公開設定レスポンス](../data/api-contract.ja.md#public-settings)。
