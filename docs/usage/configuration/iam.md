# IAM 配置

[配置手册](README.md)

## 配置入口

生成的项目将登录、密码和会话的配置写在 `config/_iam.yml`。应用启动时从 `core.config.get('iam')` 读取这些设置并传给 `iam.init()`。用环境变量覆盖时使用 `HAI_IAM_` 前缀。见[配置来源和覆盖顺序](runtime.md#配置从哪里来)。

应用先连接数据库和缓存、初始化加密模块，再运行 `iam.init()`。服务端路由仍需设置哪些请求必须登录、哪些操作需要权限。登录页用 `apiClient.iam.auth.publicConfig()` 请求服务端。服务端调用 `iam.getPublicConfig()`，只返回登录开关、密码长度等可给访客看的信息。数据库地址、LDAP 凭据和签名密钥都留在服务端。

## 配置示例

```yaml schema=@h-ai/iam:IamConfigSchema
login:
  password: true
  otp: false
register:
  enabled: false
session:
  maxAge: 3600
```

## 配置清单

有些整组设置省略后，IAM 仍会按表中默认行为运行。以 `password` 为例，省略整组密码设置时仍有默认密码规则。若给出 `password.minLength`，它只替换最短长度，其余规则仍由各字段的默认值决定。验证码、API Key、密码重置和会话的设置省略时，各功能也会使用自己的默认值。登录页只能收到允许公开的认证设置和 `ui` 中的界面选项。

### `initialCredentials`

| 配置项                       | 默认值/必填 | 说明                                                                                           |
| ---------------------------- | ----------- | ---------------------------------------------------------------------------------------------- |
| `initialCredentials`         | 可省略      | 管理端可用单次邀请代替共享初始密码；需要已配置的密码重置通知通道                               |
| `initialCredentials.enabled` | `false`     | 是否通过一次性邀请设密；开启前配置密码重置入口、用户联系方式与真实通知通道，不显示共享初始密码 |

### `reauthentication`

| 配置项                        | 默认值/必填 | 说明                                                                                                                                                        |
| ----------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `reauthentication`            | 可省略      | 指定敏感操作额外验证原密码；凭据短期且单次使用                                                                                                              |
| `reauthentication.enabled`    | `false`     | 是否让已登录用户在敏感动作前弹窗验证当前密码；不创建另一个账号的登录，也不授予额外权限                                                                      |
| `reauthentication.operations` | `[]`        | 需要二次认证的操作 ID 清单，例如 iam.users.delete；两端须已接入同名守卫，仅添加名字不会保护自定义接口。可填数组（元素为字符串，1–128 个字符），最多 1000 项 |
| `reauthentication.ttlSeconds` | `300`       | 二次认证凭据的有效秒数；仅供当前用户/会话的指定操作单次使用，取消不发送敏感业务请求。可填整数，1–900                                                        |

### `loginAccess`

| 配置项                        | 默认值/必填 | 说明                                                                                                                           |
| ----------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `loginAccess`                 | 可省略      | 服务端应用从连接或已配置的信任代理取得客户端 IP，忽略登录表单自报的 IP                                                         |
| `loginAccess.allowIps`        | `[]`        | 允许的 IPv4/IPv6 地址或 CIDR；空数组不限，最多 1000 项。可填数组（元素为字符串，IPv4 或 字符串，IPv6 或 字符串），最多 1000 项 |
| `loginAccess.denyIps`         | `[]`        | 拒绝的 IP/CIDR；拒绝优先，空数组不限，最多 1000 项。可填数组（元素为字符串，IPv4 或 字符串，IPv6 或 字符串），最多 1000 项     |
| `loginAccess.timezone`        | `"UTC"`     | 访问时间窗口使用的 IANA 时区，默认 UTC，使用服务器时钟                                                                         |
| `loginAccess.windows`         | `[]`        | 允许的访问时间窗口；空数组不限时间，最多 100 个。可填数组，最多 100 项                                                         |
| `loginAccess.windows[].days`  | 必填        | 允许窗口的开始日，周一 1 至周日 7，至少一项。可填数组（元素为整数，1–7），至少 1 项、最多 7 项                                 |
| `loginAccess.windows[].start` | 必填        | 允许窗口开始时间 HH:mm，包含开始时刻                                                                                           |
| `loginAccess.windows[].end`   | 必填        | 允许窗口结束时间 HH:mm，不含结束；早于开始表示跨午夜，不得与开始相同                                                           |
| `loginAccess.enabled`         | `false`     | 是否限制新建登录会话；已有会话的每次请求限制由 Serv/Kit 的 access 策略负责                                                     |

### `password`

| 配置项                          | 默认值/必填 | 说明                                                                                      |
| ------------------------------- | ----------- | ----------------------------------------------------------------------------------------- |
| `password`                      | 可省略      | 密码配置                                                                                  |
| `password.minLength`            | `8`         | 新设密码的最少字符数；提高后只约束新建、重置和改密，不会反查已有密码的散列。至少 1 的整数 |
| `password.maxLength`            | `128`       | 新设密码的最多字符数，须不小于 minLength；避免超长输入消耗鉴别资源。可填整数，1–256       |
| `password.requireUppercase`     | `true`      | 是否必须包含大写字母；与 minCharacterClasses 同时执行，false 仅取消这一项强制要求         |
| `password.requireLowercase`     | `true`      | 是否必须包含小写字母；false 不代表取消长度或其他字符类别条件                              |
| `password.requireNumber`        | `true`      | 是否必须包含数字；开启后所有服务端设密入口统一拒绝缺少数字的新密码                        |
| `password.requireSpecialChar`   | `false`     | 是否必须包含特殊字符；开启会增加密码输入要求，不影响已经保存的密码散列                    |
| `password.minCharacterClasses`  | `0`         | 至少包含的字符类别数（大小写、数字、特殊字符），0 不额外限制。可填整数，0–4               |
| `password.expirationDays`       | `0`         | 密码过期天数（0 表示不过期）。非负整数                                                    |
| `password.preventSamePassword`  | `false`     | 拒绝新旧密码相同；启用口令期限或首次强改时也始终拒绝相同密码                              |
| `password.requireInitialChange` | `false`     | 管理员创建或重置的初始密码必须先更换；不影响用户自行注册设密                              |

## 生效与核对

设置开关后检查登录页是否出现相应选项，并用实际账号验证。验证码登录和密码重置需要配置可用的邮件或短信服务。LDAP 登录需要配置目录连接并确认应用已提供登录路由。认证方式、账号生命周期和安全生效范围见[登录、密码、会话与权限策略](identity.md)。
