# @h-ai/tools 設定一覧

`tools.define` と `tools.createRegistry` は純粋な定義とファクトリーです。モジュール単位の YAML、環境変数、`init/close` はありません。

| 設定箇所 | フィールド | デフォルトと効果 |
| --- | --- | --- |
| ツール定義 | `name/description/parameters/handler` | 必須。名前は 1～64 文字の ASCII で、英字から始め、以降は英字、数字、アンダースコア、ハイフンを使用可能。入力は Zod で検証 |
| ツール定義 | `timeoutMs` | 0～2147483647 ミリ秒の整数。省略時は 30 秒で、呼び出し単位で上書き可能。0 は即時タイムアウト |
| レジストリ | `authorize` | 任意。設定した場合、すべてのレジストリ呼び出しで通過が必要 |
| 実行オプション | `signal` | キャンセルシグナル。処理関数にも伝達 |
| 実行オプション | `objectId/sessionId` | 信頼できる主体情報とセッションコンテキスト。未認証のモデル入力から取得してはならない |
| 実行オプション | `deadline/timeoutMs` | 絶対期限を優先し、次に呼び出し単位のタイムアウト、ツールのタイムアウト、30 秒の順 |
| 実行オプション | `authorize` | 呼び出し単位の追加認可。レジストリの認可と併せて適用 |
| 一括実行オプション | `parallel` | デフォルトは false。並列実行可能と確認した呼び出しにのみ有効化 |

有効にするツールはホストが決定します。登録しなければ呼び出せず、登録を解除すると定義一覧にも表示されなくなります。モデルに見せるツールも現在の主体に応じて絞り込み、サーバーでの実行時にも検証を続けます。

`tools.define` の名前またはデフォルトタイムアウトが無効な場合は、設定エラーとして `TypeError` をスローします。レジストリはこのメソッドで作成したツールのみを受け付け、共通の実行境界を迂回する手書きオブジェクトは受け付けません。業務から直接利用するツールには、より豊富な Schema を使えます。モデルに渡す場合は JSON Schema に変換できる必要があり、通常はオブジェクト引数を使います。

独立ジョブは Runner 環境、MCP サービス設定、固定イメージを使います。設定は対応するモジュールとホストが管理します。[Runner](runner.md)、[AI MCP](ai.md#mcp和a2a)、[ジョブの説明](../../../packages/tools/jobs/README.md)を参照してください。Tools をインストールしても、これらのサービスは起動しません。
