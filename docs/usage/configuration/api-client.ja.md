## 設定の読み込み

このモジュールには独立した設定ファイルがありません。実行時の引数は API リファレンスに記載し、YAML 項目として扱いません。

引数・既定値・使用例は次を参照 [呼び出し引数と接続オプション](../function/api-client.ja.md#call-options)。
