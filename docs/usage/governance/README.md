# 维护、安全与验收

[文档首页](../README.md)

这一章面向框架维护、代码审查和验收交付。目标是让实现承诺、资料和验证证据能够互相对照，避免“某项测试通过”被扩大成所有环境都可靠。

## 维护一次公共变更

[维护流程](framework-maintenance.md)从影响分析到调用方、模板、配置、Skills和截图同步。仓库规则与生成应用规则各有读者，公共契约一致，项目私有内容保留。

## 按风险审查安全与恢复

[安全审查](security-review.md)沿用户、请求、凭据、数据和副作用查实际执行点。问题记录触发条件、影响和可验证改法，区分源码证据、运行复现与待验证事项。

## 用证据说明验收结果

[验证、截图与适用边界](verification.md)说明单元、集成、浏览器与目标服务各自证明什么，提供可复现命令和当前截图来源。未执行和失败不得标成通过。
