# 保守・セキュリティ・検証

[ガイドのトップ](../README.ja.md)

この章は、フレームワークの公開仕様を変える場合、セキュリティをレビューする場合、リリースを検証する場合に参照してください。実装が提供する動作と、実際に確認できた範囲を対応付けます。

## 公開仕様の変更を保守する

[フレームワークの保守手順](framework-maintenance.md) では、影響範囲の確認から、呼び出し元、テンプレート、設定、Skills、スクリーンショットの更新までを説明します。フレームワークと生成されたアプリはそれぞれのルールに従います。共通の公開仕様を揃え、アプリ固有のルールを維持してください。

## セキュリティと復旧をレビューする

[セキュリティレビュー](security-review.md) では、ユーザー、リクエスト、認証情報、データ、副作用を処理する実装をたどります。問題が発生する条件、影響を受ける範囲、修正を確認する方法を記録してください。再現した結果と、ソースを読んで確認した結果を区別します。

## 検証結果を記録する

[検証・スクリーンショット・対象範囲](verification.md) は、単体テスト、統合テスト、ブラウザテスト、実サービスの確認で分かることを説明します。実行したコマンド、環境、結果、実行できなかった確認項目を残してください。
