# hai-framework usage guide

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

Start with the work you need to complete. New users can follow the [English creation-to-delivery workflow](getting-started/workflow.en.md). The new domain handbook and role-based reading paths are currently in Chinese; this entry does not imply that every chapter has been translated.

## Chapters

1. [Understand the framework](overview/README.md): capabilities, boundaries, environment requirements and [six reading paths](overview/reading-paths.md).
2. [Create your first deliverable](getting-started/README.md): create, run, develop, build and upgrade. [Complete English workflow](getting-started/workflow.en.md).
3. [Develop business capabilities](development/README.md): APIs/data, authentication/UI, AI and integrations.
4. [Manage configuration by domain](configuration/README.md): purpose, defaults, value differences, complete examples and actual result images.
5. [Deploy and operate](operations/README.md): full/incremental updates, recovery conditions, feedback and troubleshooting.
6. [Maintain, review security and validate](governance/README.md): public contracts, synchronized documentation and evidence boundaries.

Each role links to the same maintained content. The website consumes these authored Markdown files and navigation.json; configuration defaults are maintained in the domain handbook rather than copied into separate role manuals.

Check the installed version before using source features. Beta requires npm's beta tag or an exact published version; main is not proof of registry availability. [Verification](governance/verification.md) distinguishes actual runs from environment-dependent work.
