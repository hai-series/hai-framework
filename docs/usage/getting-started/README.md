# 从创建到首次交付

[文档首页](../README.md) · [环境准备](../overview/environment.md)

按顺序完成这四步，得到一份能运行、可验证并可交付的应用。已有应用可以从对应步骤继续。

## 第一步：创建并运行

[创建项目](create.md)选择正确CLI版本渠道和模板，核对目录并启动。完成时能打开页面并定位服务入口。

## 第二步：实现一个功能

[配置与开发](develop.md)接好环境、业务契约、权限和页面。完成时成功、拒绝、失败保留及恢复都能解释清楚。

## 第三步：生成对应制品

[编译与打包](build.md)区分源码编译、服务器镜像和原生安装包。完成时能核对版本、构建ID、架构和实际产物。

## 第四步：发布、验证与后续升级

进入[发布运行章节](../operations/README.md)执行完整或增量部署。后续按[升级框架](upgrade.md)迁移公开API、配置与Skills，再重新验收交付。

需要英语/日语完整传统流程时，阅读[English workflow](workflow.en.md)或[日本語の作成・配布手順](workflow.ja.md)。新的领域手册当前为中文，三语入口不会把中文正文标成已翻译。
