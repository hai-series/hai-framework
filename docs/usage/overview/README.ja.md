# フレームワークを知る

[ガイドのトップ](../README.ja.md)

アプリの構成を決め、実行に必要なツールを準備します。

## 必要な機能を選ぶ

[主な機能とアプリ構成](framework.ja.md) では、モデルの呼び出し、独立した API、同一オリジンの Web アプリ、複数クライアント向けアプリの構成を説明します。既存のプロジェクトに機能を追加する場合は、その機能を提供するパッケージの公開 API から始めてください。

## 作業に合った手順を探す

[目的別の読み方](reading-paths.ja.md) から、初めて使う人、開発者、設定管理者、運用担当者、フレームワークの保守担当者、セキュリティレビュー担当者向けの手順を探せます。

## 実行環境を準備する

[開発・デプロイ・ネイティブ環境](environment.ja.md) に、開発、ブラウザテスト、コンテナ、ネイティブアプリのビルドに必要なツールをまとめています。CLI はインストール済みのツールを検出します。必要なツールのインストールやコンテナエンジンの起動を済ませてから、対象の確認を実行してください。
