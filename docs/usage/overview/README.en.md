# Understand the framework

[Guide home](../README.en.md)

Choose an application structure and prepare the tools needed to run it.

## Decide how much to adopt

[Capabilities and application structure](framework.en.md) compares a model call, a standalone API, a same-origin web app, and a multi-client application. In an existing project, start with the public API of the package that solves your task.

## Find the right starting point

[Reading paths by task](reading-paths.en.md) links to the steps for first-time users, developers, configuration owners, operators, framework maintainers, and security reviewers.

## Prepare the environment

[Environment and tooling](environment.en.md) lists what you need for development, browser tests, containers, and native packaging. The CLI can discover installed tools. Install missing tools or start the required engine before running the corresponding check.
