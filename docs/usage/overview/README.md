# 认识框架与选择路线

[文档首页](../README.md)

这一章帮助你决定是否使用框架、从哪里开始，以及当前环境还缺什么。读完不需要记住所有包名，应能选出适合当前任务的下一步。

## 先判断框架是否适合当前工作

阅读[能力、边界与应用结构](framework.md)，了解最小AI调用、独立API、同源Web与多端应用各自的组合。已有项目只接一个能力时，从对应包公开入口开始，不必创建完整应用。

## 再按职责确定顺序

[阅读路线](reading-paths.md)为初次使用、开发人员、配置管理、运维部署、框架维护和安全审查分别给出目标与顺序。它们链接同一份操作和配置正文，避免同一参数出现多套解释。

## 最后准备本次真正需要的环境

[环境准备](environment.md)区分开发、浏览器验收、容器交付与原生安装。自动探测不会安装工具或启动引擎；缺少真实前置条件时，先补环境再把结果称作验收通过。
