# hai-ui-review

## 能力契约

| 项目 | 契约 |
| --- | --- |
| 能力 | 根据用户任务与真实渲染检查界面体验和技术质量 |
| 适用场景 | 界面走查、前端改动自查、布局/交互评审与已授权修复验收 |
| 输入 | 目标页面/组件、需求或设计约定、运行环境、实际界面与相关实现 |
| 输出 | 带位置、操作、后果和截图/运行证据的问题清单及复测结果 |
| 限制 | 只读请求不自动修改；审美偏好单列，不能推翻明确设计。浏览器证据不等于原生平台或真实外部服务验收。 |


## 使用路径

读取 [完整工作流程与按需参考](../../../packages/cli/templates/skills/hai-ui-review/SKILL.md)，共享契约只在该位置维护。仓库开发先按 [工作规范](../../instructions/workspace.md) 选择模块、应用与测试规范；框架 API 以本仓库真实公开导出与类型核验，发布包消费者以安装版本核验。

公共变化同步 packages、apps、CLI 模板、README、skills、LLMS 与受影响测试。只读审查和仅规划请求按其范围交付；已有实现/修复授权按流程继续，验证结果关联当前代码和实际环境。
