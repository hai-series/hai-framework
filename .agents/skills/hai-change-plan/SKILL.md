# 变更影响与方案确认

## 能力契约

| 项目 | 契约 |
| --- | --- |
| 能力 | 在重要框架改动前提出可决定的方案，确认后同步实现、文档与验证 |
| 适用场景 | 框架新增、修改、删除功能或修复中涉及结构、配置、核心流程、模块边界 |
| 输入 | 用户目标、实际差异、调用方、已有方案与授权 |
| 输出 | 简明方案、影响范围、用户决定、同步与验证结果 |
| 限制 | 对未确认的重要方案先等待；已经明确同意且影响未扩大的方案不重复确认 |

读取[共享流程正文](../../../packages/cli/templates/skills/hai-change-plan/SKILL.md)，触发范围、确认边界与同步要求只在该处维护。仓库影响分析覆盖 `packages/*`、`apps/*`、CLI 模板及文档站的实际消费者，按[工作规范](../../instructions/workspace.md)执行。
