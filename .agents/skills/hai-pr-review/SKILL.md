# hai-pr-review

## 能力契约

| 项目 | 契约 |
| --- | --- |
| 能力 | 对固定 PR/提交/分支差异进行审查，核对需求、调用影响与交付条件 |
| 适用场景 | 用户要求差异审查、开发后的交付自查或 PR 准备度评估 |
| 输入 | 实际 base/head、需求与计划、完整 diff、相关实现和 CI/运行证据 |
| 输出 | 可定位发现、实际覆盖范围、验证缺口和交付结论 |
| 限制 | 只读审查不自动改代码或发布评论；已有修复授权持续有效。审查不赋予远端推送、合并或发布授权。 |


## 使用路径

读取 [完整工作流程与按需参考](../../../packages/cli/templates/skills/hai-pr-review/SKILL.md)，共享契约只在该位置维护。仓库开发先按 [工作规范](../../instructions/workspace.md) 选择模块、应用与测试规范；框架 API 以本仓库真实公开导出与类型核验，发布包消费者以安装版本核验。

公共变化同步 packages、apps、CLI 模板、README、skills、LLMS 与受影响测试。只读审查和仅规划请求按其范围交付；已有实现/修复授权按流程继续，验证结果关联当前代码和实际环境。
