# hai-ui-design

## 能力契约

| 项目 | 契约 |
| --- | --- |
| 能力 | 把用户目标转为适配当前 Hai 组件、主题与平台的页面设计 |
| 适用场景 | 新页面、新业务流程、信息结构/布局调整或建立应用视觉约定 |
| 输入 | 用户任务、需求/验收、目标端、当前页面、组件公开类型和已有品牌/设计规则 |
| 输出 | 页面结构、状态与交互、组件映射、必要的全局/页面设计约定和可观察验收 |
| 限制 | 方案请求停在设计；已有实现授权时继续交给 app-create/ui。设计不能补定权限等未决业务规则，组件 API 以实际版本为准。 |


## 使用路径

读取 [完整工作流程与按需参考](../../../packages/cli/templates/skills/hai-ui-design/SKILL.md)，共享契约只在该位置维护。仓库开发先按 [工作规范](../../instructions/workspace.md) 选择模块、应用与测试规范；框架 API 以本仓库真实公开导出与类型核验，发布包消费者以安装版本核验。

公共变化同步 packages、apps、CLI 模板、README、skills、LLMS 与受影响测试。只读审查和仅规划请求按其范围交付；已有实现/修复授权按流程继续，验证结果关联当前代码和实际环境。
